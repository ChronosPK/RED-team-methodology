# Controlled Romanian translation termbase

This file governs the Romanian edition of the Red Team Methodology. It is a
publication-control aid and is not part of the issued document set.

## Editorial rules

- Preserve every paragraph identifier, annex letter, template identifier,
  table row, checklist item, cross-reference, URL and normative modal.
- Translate meaning completely. Do not omit, summarise, embellish or weaken a
  control. Prefer formal, idiomatic Romanian over English word order.
- Use Romanian diacritics `ă`, `â`, `î`, `ș` and `ț`; never use cedilla forms.
- Use sentence case for Romanian headings except the publication title and
  classification markings, which remain uppercase.
- Use Romanian quotation marks `„...”` in prose. Preserve literal command
  strings, code, paths, identifiers, hashes and source titles when required for
  traceability.
- Retain official names, registered framework names, cyber role names and
  established cyber terminology in English. Explain them in Romanian at first
  use or in the lexicon; do not translate a familiar English term into an
  artificial Romanian calque merely because an official translation exists in
  a separate regulatory context.
- Preserve `shall`, `should` and `may` as distinct normative levels:
  `trebuie`, `ar trebui` and `poate`. In negative requirements, use `nu trebuie`
  for prohibition and avoid the ambiguous `nu va`.
- Translate role names consistently as institutional functions. References to
  the person holding a role use `titularul funcției` where needed for clarity.
- Translate `email` as `e-mail`, following standard Romanian administrative
  usage. Never use `poștă electronică` in this edition.
